# 🚀 Atividade Prática 01: Desenvolvimento Web & GitHub

Seja bem-vindo(a) à primeira atividade prática! Neste exercício, você vai organizar suas pastas de projeto no servidor local, criar seus arquivos de código HTML e CSS, ler e preencher as lacunas solicitadas e, ao final, publicar tudo no seu perfil do GitHub mencionando o professor.

**Data de disponibilização:** 14/09/2026

---

## 📌 Passo a Passo de Execução

### 1️⃣ Organização da Pasta no VS Code
1. Abra o **VS Code**.
2. Navegue até a sua pasta de trabalho dentro do diretório do servidor local `htdocs` (exemplo: `htdocs/seu-nome/`).
3. Dentro da pasta `html`, crie uma nova pasta chamada **`exercicio-01`**.
   > ⚠️ Evite espaços no nome da pasta (use hífen `-` ou underline `_`). Espaços podem causar erro em comandos de terminal e no Git.

---

### 2️⃣ Criação dos Arquivos
Dentro da pasta **`exercicio-01`**, crie os dois arquivos a seguir:
- `index.html`
- `style.css`

---

### 3️⃣ Cópia e Preenchimento dos Códigos
1. Acesse a pasta acima *Atividade 01 HTML* nesse repositório disponibilizado pelo professor no GitHub.
2. Copie os códigos de exemplo e cole nos seus respectivos arquivos (`index.html` e `style.css`) recém-criados no VS Code.
3. Leia atentamente as instruções contidas nos comentários do próprio código.
4. Substitua todos os campos e lacunas marcados com **`___`** pelas suas informações e soluções da atividade.

---

### 4️⃣ Teste Local
1. Instale a extensão **Live Preview** (Microsoft) no VS Code (se ainda não tiver).
2. Clique com o botão direito em `index.html` e selecione **"Show Preview"**.
3. Deixe a aba de preview aberta ao lado do código: com o **Live Preview**, qualquer alteração salva em `index.html` ou `style.css` é refletida automaticamente na tela, permitindo acompanhar em tempo real o que está acontecendo enquanto você edita.
4. Confira se o conteúdo e o estilo estão sendo aplicados corretamente.
---

### 5️⃣ Publicação no GitHub (upload direto pelo navegador)
1. Acesse [github.com](https://github.com) e faça login no seu perfil.
2. Clique em **"New repository"** e crie um novo repositório (ex: `atividade-01-web`).
   - Marque a opção **"Add a README file"** ao criar (facilita o próximo passo).
3. Dentro do repositório recém-criado, clique em **"Add file" → "Upload files"**.
4. No seu computador, abra a pasta `htdocs/seu-nome/html/` no explorador de arquivos (fora do VS Code).
5. Arraste a pasta inteira **`exercicio-01`** (com `index.html` e `style.css` dentro) para a área de upload do GitHub.
   > ⚠️ Confira depois do upload se o GitHub manteve a estrutura de pastas (`exercicio-01/index.html` e `exercicio-01/style.css`), e não os arquivos soltos na raiz.
6. Role até o final da página e clique em **"Commit changes"** para confirmar o envio.
7. No GitHub, clique no arquivo `README.md` do repositório e depois no ícone de lápis (✏️) para editá-lo. Cole o texto do modelo abaixo, preenchendo os campos entre colchetes, e clique em **"Commit changes"** novamente para salvar.
8. Mencione o professor **@eduardo97mendes** no campo indicado do README (isso o notifica automaticamente no GitHub).
