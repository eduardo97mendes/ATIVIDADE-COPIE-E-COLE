# 🚀 Atividade Prática 01: Desenvolvimento Web & GitHub

Seja bem-vindo(a) à primeira atividade prática! Neste exercício, você vai organizar suas pastas de projeto no servidor local, criar seus arquivos de código HTML e CSS, ler e preencher as lacunas solicitadas e, ao final, publicar tudo no seu perfil do GitHub mencionando o professor.

---

## 📌 Passo a Passo de Execução

### 1️⃣ Organização da Pasta no VS Code
1. Abra o **VS Code**.
2. Navegue até a sua pasta de trabalho dentro do diretório do servidor local `htdocs` (exemplo: `htdocs/seu-nome/`).
3. Dentro da pasta `html`, crie uma nova pasta chamada **`exercicio 01`**.

---

### 2️⃣ Criação dos Arquivos
Dentro da pasta **`exercicio 01`**, crie os dois arquivos a seguir:
- `index.html`
- `style.css`

---

### 3️⃣ Cópia e Preenchimento dos Códigos
1. Acesse o repositório disponibilizado pelo professor no GitHub.
2. Copie os códigos de exemplo e cole nos seus respetivos arquivos (`index.html` e `style.css`) recém-criados no VS Code.
3. Leia atentamente as instruções contidas nos comentários do próprio código.
4. Substitua todos os campos e lacunas marcados com **`___`** com as suas informações e soluções da atividade.

---
