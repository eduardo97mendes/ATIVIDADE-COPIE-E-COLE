O que a gente vai construir?

Um site de delivery (comida em casa) chamado Sabor Express. A pessoa vê os lanches, preenche um pedido e o PHP mostra um resumo na tela.

  1. Cardápio (index.html) — os produtos em cartõezinhos, com nome, descrição e preço.
  2. Formulário (pedido.html) — nome, telefone, endereço, produto e quantidade.
  3. Visual (style.css) — cores e layout. Já está ligado no HTML com <link rel="stylesheet" href="style.css">.
  4. PHP — quando a pessoa clica em Enviar, os dados vão para processar.php. As regras (se faltou nome, quanto custa, etc.) ficam em funcoes.php. Você não mistura PHP no HTML do cardápio.

Como fazer (3 passos em cada arquivo)

Abra os arquivos no editor (Cursor, VS Code, etc.). Não dá para completar o exercício só olhando o site no navegador. Os comentários no código explicam o exemplo e o que você precisa escrever.

  1. Exemplo pronto — já está feito. Leia o comentário “o que a gente fez” e copie a ideia.
  2. Com dica — falta um pedaço. Tem TODO e um modelo de código para você completar.
  3. Desafio — você cria mais 2 ou 3 iguais, sozinho.

Ordem boa para não se perder: 1) index.html → 2) pedido.html → 3) style.css → 4) funcoes.php.

processar.php e mensagens.php já estão prontos. Só leia os comentários para entender o caminho: formulário → PHP → resumo na tela.

Como abrir o site

No terminal, entre na pasta aluno e rode:

php -S localhost:8000

Depois abra o cardápio e o pedido. Se o PHP não estiver rodando, o formulário não mostra o resumo.
